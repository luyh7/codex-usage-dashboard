# 1.1.0

在桌面查看 Codex 用量、费用和会话统计。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows（64 位） | [下载 .exe](https://github.com/luyh7/codex-usage-dashboard/releases/download/v1.1.0/cousash-1.1.0-windows-x64-setup.exe) |
| macOS（Apple Silicon） | [下载 .dmg](https://github.com/luyh7/codex-usage-dashboard/releases/download/v1.1.0/cousash-1.1.0-macos-arm64.dmg) |

## 功能

- 自动发现本机日志，也可选择其他日志文件夹。
- 导入、导出设备快照，汇总多台设备的用量。
- 保存语言、时区和窗口设置。

## 安装与更新

Windows 运行安装器；Mac 打开 DMG，将应用拖入 Applications 后打开。

当前版本请下载新版安装包手动更新，原有设置和导入数据会保留。首次打开如遇系统提示，参见[安装帮助](https://github.com/luyh7/codex-usage-dashboard/blob/main/docs/desktop.md)。
