# 1.1.0

This feature release adds Windows, macOS and Linux desktop client code sharing the Rust statistics core and Svelte dashboard. Desktop stable support is limited to the validated Windows 11 x64 build 22631 with existing WebView2 and macOS 26.6.2 arm64 environments. Intel Mac, older systems and independent Linux GUI environments remain outside that desktop stable commitment.

Desktop packages include their matching native helper, source/file dialogs, persistent settings, imports/exports, single-instance service isolation and signed HTTPS whole-application updates. Windows packages are unsigned at the OS level; Mac packages use ad-hoc signatures without Developer ID/notarization. Keep system security protections enabled and follow prompts for the individual verified application. Known limitations and rollback links are in the [desktop release notes](https://github.com/luyh7/codex-usage-dashboard/blob/main/docs/releases/desktop-v1.1.0.md).

Version 1.1.0 corrects the desktop feature-release number previously published as 1.0.1. The existing 1.0.1 packages remain available for rollback. This version change introduces no business-data migration or application-logic changes beyond the reviewed PR #9 implementation.

## Install as a skill

```bash
npx skills add luyh7/codex-usage-dashboard -g -a codex -y
```

Invoke `$codex-usage-dashboard` in Codex. The skill downloads and verifies the matching release program on first use or after a version change. Matching installations are reused offline. Node.js 18+ is needed for the runtime check; no Rust or Python installation is required.

Alternatively, install the skill and open the dashboard immediately:

```bash
npx github:luyh7/codex-usage-dashboard#v1.1.0 -- --open
```

## Run without a skill

Choose the executable whose filename contains your platform:

| Platform | Filename contains |
| --- | --- |
| Windows x64 | `windows-x64` (ends in `.exe`) |
| Linux x64 (glibc; built on Ubuntu 22.04) | `linux-x64` |
| macOS Intel | `darwin-x64` |
| macOS Apple Silicon | `darwin-arm64` |

Each executable embeds the dashboard. No skill, Node.js, Python, or Rust is required. `manifest.json` is used by the skill installer; `SHA256SUMS` lets manual downloads be checked. GitHub's automatic source archives are for developers and do not contain the compiled program.

On Windows, save the `.exe` in a permanent folder and run it. On macOS/Linux, rename the downloaded file to `codex-usage-dashboard`, then run:

```bash
chmod +x ./codex-usage-dashboard
./codex-usage-dashboard
```

The program starts a local background service and opens your browser. Keep the executable in place while the service is running. Run the same file with `--stop` to stop it, `--no-browser` for a headless launch, or `--shortcut` to create a desktop/application-menu entry.

These executables are not code-signed or notarized. Windows or macOS may require you to explicitly allow the downloaded program using the operating system's security settings. Linux ARM, Windows ARM, and musl/Alpine builds are not included in this release.

## Upgrading

Update the skill using your skill manager; its next invocation installs the matching runtime. Stop an older Python dashboard before migrating if it owns port 8765. For manual downloads, stop the old program with `--stop`, then run the new executable. Do not delete your configuration or imported snapshots.

Usage stays local. Cost figures are estimates from model pricing, not subscription charges. Remote-device synchronization remains manual.
