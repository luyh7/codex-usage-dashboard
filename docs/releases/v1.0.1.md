## 安装与更新 · Install & update

Windows 运行安装器；Mac 打开 DMG，将应用拖入 Applications 后打开。<br>
On Windows, run the installer. On Mac, open the DMG, drag the app to Applications, then open it.

当前版本请下载新版安装包手动更新，原有设置和导入数据会保留。<br>
Update manually by downloading the latest installer. Your settings and imported data are kept.

首次打开如遇系统提示，参见[安装帮助](https://github.com/luyh7/codex-usage-dashboard/blob/main/docs/desktop.md)。<br>
For security prompts on first launch, see the [Mac](https://support.apple.com/guide/mac-help/mh40616/mac) or [Windows](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) installation help.
