## 更新 · Changes

- 按 OpenAI 官方费率估算 GPT-6.2 Astra 和 Sol 的用量成本，涵盖长上下文及 Ultrafast 限时优惠。<br>Estimate GPT-6.2 Astra and Sol costs using OpenAI API rates, including long context and the Ultrafast promotion.
- 从较早的检查点恢复会话时，修复用量重复统计。<br>Fix double-counted usage when resuming a session from an older checkpoint.
- 保留已停止的 WSL 发行版的缓存统计，优化网络共享目录的轮询和服务退出。<br>Keep cached statistics for stopped WSL distributions, and improve polling and shutdown for network sources.
