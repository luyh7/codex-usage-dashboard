# 1.1.3

改进桌面更新体验和长任务进度，并让设备快照导出文件名更易识别。

Improve the desktop update experience and long-running task progress, and make device snapshot exports easier to identify.

## 功能 · Features

- 桌面更新窗口显示版本说明和下载进度。<br>Show release notes and download progress in the desktop update dialog.
- 索引和导入快照时显示进度与耗时。<br>Show progress and elapsed time while indexing or importing snapshots.
- 导出的快照文件名包含设备名称。<br>Include the device name in exported snapshot filenames.

## 安装与更新 · Install & update

Windows 运行安装器；Mac 打开 DMG，将应用拖入 Applications 后打开。<br>On Windows, run the installer. On Mac, open the DMG, drag the app to Applications, then open it.

1.1.1 及更新版本可在应用内检查更新；1.0.1 和 1.1.0 请下载安装包手动更新。原有设置和导入数据会保留。<br>From 1.1.1 onward, check for updates in the app. From 1.0.1 or 1.1.0, download the installer. Your settings and imported data are kept.

首次打开如遇系统提示，参见[安装帮助](https://github.com/luyh7/codex-usage-dashboard/blob/main/docs/desktop.md)。<br>For security prompts on first launch, see the [Mac](https://support.apple.com/guide/mac-help/mh40616/mac) or [Windows](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) installation help.
