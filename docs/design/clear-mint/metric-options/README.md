# 顶部统计卡候选方案

三套方案沿用 Clear Mint 的四卡布局、费用强调色和视觉层级。2026-10-22 用户选定组合：**总用量采用“趋势洞察”的每日用量，对话数采用“用量构成”的主会话 / 子代理构成**；费用与缓存命中率采用“用量构成”稿中的完整样式，包括费用范围、零起点与横轴日期，以及纯色缓存圆环与缓存 / 输入数量。总用量柱图不常驻文字，四类图表均支持悬停与聚焦提示。该组合已作为实现基准。

费用卡在三套方案中保持一致：从所选范围起点的 0 开始，按真实每日费用累计，终点与卡片金额一致。缓存命中率使用缓存输入 Token / 全部输入 Token。

## 数据口径

- 全部方案使用 [source-data.json](source-data.json) 中同一份本机数据快照，范围为 2026-10-19 至 2026-10-22，时区 Asia/Shanghai。图中时间为快照更新时间。
- 费用为 $226.57，总用量为 369.94M tokens，区间去重对话数 60，主会话 59，子代理 1。数据仍会在实际应用中继续变化。
- 所有图形由快照中的数值计算，没有随机柱高、虚构增长率或补绘的数据点。累计费用的逐日舍入误差小于 $0.00001。
- 每日有用量的对话数是 7、11、42、8。同一对话可以跨日出现，不能将它们相加作为区间去重对话总数。
- 缓存输入是全部输入的子集，因此用量构成取“缓存输入 + 未缓存输入 + 输出”；推理输出已包含在输出中，不重复相加。
- 日均按选定的自然日数计算，包含尚未结束的今日。单日峰值与每日用量使用相同的范围和时区。
- 费用曲线在本次多日快照中使用日粒度。后续实现单日视图时，需要真实的小时聚合；没有原始明细时不生成虚构的日内曲线。

预览支持三种方案切换、卡片高度调整和每日数值标注开关，并验证了 1024 / 736 / 390 / 320px 宽度。
