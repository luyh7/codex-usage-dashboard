## 核心视觉原则

- 冷白背景、白色面板、薄荷色交互，费用使用深绿强调。
- 视觉层级依次突出总费用、选中会话、辅助信息；四张统计卡保留不等宽布局。
- 桌面列表与详情并排、各自内部滚动，顶部标题与统计卡保持可见；窄屏使用详情和日历浮层。
- 使用本地 Inter / Dashboard Sans 字体，以紧凑正文、清晰数字层级和适量留白组织信息。
- 图表展示当前筛选范围内的真实数据，使用累计费用曲线、用量柱图、会话构成和缓存圆环。
