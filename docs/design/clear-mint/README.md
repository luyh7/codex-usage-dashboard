概览稿定义统计卡、字体层级、布局、间距、选中态、图表与详情区的样式。2026-10-22 用户明确指出旧项目稿不正确，要求以概览为基准重新生成；旧项目稿不再用于指导还原。日历稿定义右上角浮层的位置、范围选择和底部操作。

## 实现基准

- 项目/对话截图用于参考信息布局；保留新版树状连线和会话气泡图标。按项目展示时，暖橙色「归档」标签放在会话标题左侧，主会话与子代理一致。
- 所有下拉选择统一复用 `Dropdown.svelte`：排序、四项筛选、语言、密度、移动端时间范围，以及日历月份和「更多」。使用白色浮层、薄荷色选中态和勾选标记，支持方向键、输入检索、Escape 与外部点击关闭；浮层避开视口边缘，并且不受面板滚动区裁切。日历年份保留直接输入。
- 只保留一个「概览」页面，列表内切换「按项目 / 按对话」，默认按项目展示、按最近更新降序排列。项目标题显示环境、对话数与最近活动时间，对话标题右侧显示相对时间；按对话展示时，将环境和项目名放在标题下方。排序使用自定义浮层，支持键盘操作及外部点击/Escape 关闭。
- 160px 侧栏；桌面主区左间距 28px，右间距 23px；卡片圆角 15–16px。
- 冷白背景 `#f6fafc`、白色面板、深蓝黑正文 `#16263f`、标题 `#08151f`、次要文字 `#617593`。
- 主色 `#00a469`、费用深绿 `#004a37`、选中背景 `#e8faf2`，细边框 `#e3ecf4`。
- 保留概览稿约 192px 高的不等宽统计卡：费用卡内累计费用曲线（零起点、起止日期与范围说明）、总用量卡内每日用量柱图（日期与数值仅悬停显示）、对话数卡内主会话与子代理构成条及数量、缓存命中率纯色圆环与“缓存 / 输入”数量。项目页沿用同样的高度与视觉层级。四类图表悬停或键盘聚焦时显示实际数值提示。
- 顶部卡片的迷你图表按当前时间范围、时区与筛选条件，从真实事件统计费用、用量和活跃对话；未知计价不按零费用绘图。短窗口和窄屏压缩卡片高度，优先保留可用的列表空间。
- 正文字号以 13–14px 为主，桌面会话标题 14px，常规会话行约 48px；主金额保留视觉强调。紧凑密度可进一步减少行高。
- 列表/详情的比例、卡片位置与留白遵循概览稿；右侧详情保留独立的大金额、用量走势和费用构成。日历为 712px 浮层，展开时不移动页面内容。
- 页面固定在当前视口内，列表和详情卡片占满下方可用高度并分别内部滚动；滚轮不会移动顶部标题和统计卡，分页入口固定在列表底部。
- 英文与数字使用本地提供的 [Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1) 可变字体，数字根据层级使用 720–780 字重，许可见 [Inter-OFL.txt](../../../web/src/assets/fonts/Inter-OFL.txt)。常用简体中文由 Dashboard Sans（Noto Sans CJK SC 子集）覆盖，许可见 [OFL.txt](../../../web/src/assets/fonts/OFL.txt)。其他字符回退到系统中文无衬线字体。
- 展开分组保留汇总数值，不显示“任务合计”标签；主会话行直接显示对话标题，并在右侧显示“主会话”标签，与子代理行保持一致。选中的主会话或子代理与右侧详情保持同一统计范围。已完成的单页列表不显示无效分页按钮。
- 保留项目与组内的双层树线；组内竖线从分组标题下半部开始，主会话与子代理均显示短横线，两层横线长度一致。主会话和子代理行高一致，角色标签不加描边；主会话标签使用稍深的灰蓝底 `#dfe9f3`、略深的文字与 500 字重，子代理保持浅灰底和 400 字重。标签右侧显示相对时间。
- 界面统一使用“主会话 / 子代理”（英文 Main thread / Subagent），对应 [OpenAI 官方子代理文档](https://learn.chatgpt.com/docs/agent-configuration/subagents) 的 main thread / main chat 和 subagent 术语。
- 统计对象统一称为“会话”（英文 session），数量使用“个会话”；主会话及其子代理的汇总分组称为“会话组”（session group），展开与收起按钮按会话组计数。
- 主会话详情保留两项折叠入口：用量事件、更多信息。原有消息、工具、计价区间、环境和元数据可在更多信息中查看。
- 日历日期选择先保留为草稿，应用后才更新查询；支持取消、点击外部、Escape、键盘选择、跨月范围和输入起止日期。
- 日期选择器以原生模态浮层显示全局遮罩，遮罩覆盖侧栏及主区，点击遮罩取消草稿并关闭。设备数据弹窗同样支持外侧点击关闭；偏好、统计细分和筛选支持点击外部关闭。
- 桌面按照原稿校准，窄屏将详情与日历改为可操作的浮层，并保留减少动画的系统偏好。

## 数据与稿件的区别

顶部统计卡方向见 [三套真实数据设计方案](metric-options/README.md)。2026-10-22 用户选定组合：总用量采用“趋势洞察”的每日用量，对话数采用“用量构成”的主会话与子代理构成，费用保留所选范围累计费用走势。统计基于完整筛选范围，不受当前列表分页影响。

实际页面显示真实数据，因此不显示“演示数据”或虚构增长率；统计卡内的趋势图应来自同一查询范围的真实数据。不能用旧项目稿中的矮统计卡替换概览的卡片样式。本周、本月结束日期遵循 API，统计到当天。日历的更多选项保留已有近 30 天和全部时间功能。

浏览器校验用 [clear_mint.mjs](../../../tools/fixtures/clear_mint.mjs) 提供原稿中的项目、费用和用量，避免修改用户日志或快照。验证截图保存在 `output/verification/clear-mint/`，不替代本目录中的原始设计稿。

固定布局、内部滚动、卡片密度和全局遮罩使用 [verify_overview_layout.mjs](../../../tools/verify_overview_layout.mjs) 验证，截图位于 `output/verification/overview-layout/`。可通过 `PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_EXECUTABLE_PATH` 指定本机浏览器测试依赖。
